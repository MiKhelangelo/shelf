    THE LOCAL WORKFLOW

    From a link to your library.

    This is a static web app. It can make a script and read files you choose; it can’t download videos or watch your disk itself.

    1. 1

      Collect your links

      Paste Instagram post or Reel URLs. Choose which items to include in the save script.

    2. 2

      Install the downloader once

      With Homebrew already installed on your Mac, run:

      brew install yt-dlp

      Or follow the official yt-dlp instructions. Shelf doesn’t install anything for you.

    3. 3

      Review and run your script

      Get the script below. If it’s in Downloads, run:

      cd ~/Downloads && bash shelf-instagram.sh

      Files go to ~/Movies/Shelf/<shortcode>/. The script contacts Instagram and its media hosts. It doesn’t use cookies or sign in.

    4. 4

      Open your saved folder

      Choose the Shelf folder here. Captions and creators become searchable. Local videos are available to play until you close or reload the page; reopen the folder to reconnect them.

    Some posts won’t save. Instagram may require login, block requests, or remove a post. Photo-only posts may be unsupported. Failed links are recorded for review; Shelf doesn’t bypass access restrictions.
    Inspect the script before running it
    Add and select a link to preview your generated script.

    The page sends no library or file data to a service. The host still receives normal page requests. Browser storage can be cleared; a JSON export backs up links and metadata, not your videos.
